# Roadmap

## Hackathon completion

- Finish host wiring for FluxFlow, FluxLedger and FluxProof.
- Run the Anchor registry test suite after the latest lifecycle hardening.
- Deploy the registry to Devnet and record its program address.
- Exercise the real Solana adapter with disposable test assets.
- Record one verified accepted transaction and one genuine policy rejection.
- Replace every pending label with either evidence or an explicit limitation.

## 0–3 months — harden

- Evaluate extraction against labelled synthetic and consented contracts.
- Audit the program, upgrade authority and signer boundaries.
- Add durable idempotency, reconciliation and recovery for unknown transaction outcomes.
- Conduct design-partner interviews before asserting demand.

## 3–9 months — broaden

- Amendments, renewals and multi-vendor mandate portfolios.
- Multi-party finance approvals and role-based access.
- Read-only ERP/accounting exports and audit bundles.
- Provider-neutral AI deployment and stronger privacy controls.

## Production gate

Mainnet or real funds require an independent security review, legal analysis, resolved key policy, monitoring, durable storage and a customer-approved operating model.
